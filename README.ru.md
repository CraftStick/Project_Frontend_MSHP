# History of C++

[English](README.md) · [Русский](README.ru.md)

Многостраничный статический сайт об истории языка программирования C++.

## Возможности

- Страницы: главная, зарождение, стандарты, галерея и контакты
- Собственная страница 404
- Чистые HTML и CSS, без сборки

## Начало работы

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

## Структура проекта

- `index.html`, `origins.html`, `evolution.html`, `gallery.html`, `contacts.html`, `404.html` — страницы сайта
- `css/` — стили
- `img/`, `media/` — изображения и медиа
