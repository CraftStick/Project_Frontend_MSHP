Эволюция стандартов C++

Хронология стандартов

1998

C++98 / C++03

Первый международный стандарт. STL от Александра Степанова, шаблоны, исключения, пространства имён. C++03 — техническая правка без крупных нововведений.

2011

C++11

«Современный» C++: auto, nullptr, лямбды, умные указатели, move-семантика, потоки (std::thread), uniform initialization.

2014

C++14

Улучшения C++11: generic lambdas, return type deduction, digit separators, std::make_unique.

2017

C++17

std::optional, std::variant, structured bindings, filesystem, parallel algorithms.

2020

C++20

Концепты, модули, coroutines, ranges, форматирование std::format, трёхстороннее сравнение <=>.

2023

C++23

std::expected, mdspan, улучшения ranges и constexpr, расширение стандартной библиотеки.
