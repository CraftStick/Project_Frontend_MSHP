# History of C++

[English](README.md) · [Русский](README.ru.md)

A multi-page static website about the history of the C++ programming language. The interface is in Russian.

## Features

- Pages: home, origins, standards, gallery and contacts
- Custom 404 page
- Plain HTML and CSS, no build step

## Getting Started

Open `index.html` in a browser, or serve the folder with a local server:

```bash
python3 -m http.server 8000
```

## Project Structure

- `index.html`, `origins.html`, `evolution.html`, `gallery.html`, `contacts.html`, `404.html` — site pages
- `css/` — styles
- `img/`, `media/` — images and media
